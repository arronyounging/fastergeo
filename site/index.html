Monitoring tools count mentions and citations. But for most brands the problem starts far earlier: the AI has never heard of you — or worse, thinks you're someone else. FasterGEO measures every stage, with an LLM judge that must quote its evidence.

What you get

Not a dashboard. A closed loop.

⚙️ Machine-verified tickets

Findings become tickets with acceptance criteria a program can check. Done means a re-crawl proved it — and it flips back to regressed if the fix rots. No verbal confirmations.

🔍 Recognition judging

knows / unknown / confused — every confusion verdict carries a quote from the actual AI answer. Brand-entity risk you can act on.

🚧 Fabrication-gated content

Drafts are generated only from your sourced fact store. Every number that can't be traced to a confirmed fact is flagged. AI that can't invent things about you.

🀄 CJK-first metrics

Word-equivalent counting, full-width sentence handling, Chinese segmentation. Latin-only text metrics silently break on Chinese content — ours don't.

🔑 Zero-key mode

No API keys? Export manual sampling sheets, fill them from any AI's web UI, import back into the exact same metrics pipeline.

📏 Reproducible numbers

Unmeasured renders as unmeasured — never a fabricated zero. Single-period changes are observations; only two consecutive same-direction changes count as a trend.

Quickstart

Six commands, full loop.

Step 1 · Bootstrapnpx fastergeo bootstrap --root https://yoursite.com --llm glmDerive brand facts, competitors and a question bank from your site — nothing invented
Step 2 · Auditnpx fastergeo audit --root https://yoursite.com --urls /,/about,/pricingSee exactly what AI crawlers see — no API key needed
Step 3 · Cyclenpx fastergeo cycle --dir ./my-brandSample engines, compute funnel metrics, generate tickets, render the report — one command
Step 4 · Verifynpx fastergeo verify --tickets tickets.json --root https://yoursite.comFixed something? The machine confirms it — or flips it back when it regresses

FAQ

Questions, answered directly.

What is GEO (Generative Engine Optimization)?

GEO is a practice of making AI engines — ChatGPT, Claude, Perplexity, Doubao, DeepSeek — mention and cite your brand when users ask for recommendations. Unlike SEO, which optimizes for ranked links, GEO optimizes for being part of the answer itself.

Is it really free?

Yes. Apache-2.0, self-hosted. You bring your own engine API keys — or none, using manual sampling sheets. There is nothing to subscribe to and your data never leaves your machine.

Which engines are covered?

15 engines across two markets: ChatGPT, Claude, Gemini, Grok and Perplexity globally; GLM, Doubao, DeepSeek, Kimi and MiniMax in China via API — plus manual sheets for Baidu AI, Nano AI, ChatGPT/Claude web and Google AI Overviews.

Do I need API keys?

No. Auditing needs zero keys. Sampling uses whatever keys you have; engines without keys fall back to manual sheets that import into the same pipeline.

How is this different from AI visibility monitors?

Three ways: it measures the head of the funnel (does AI even know you — or confuse you with someone else) with quoted evidence; it closes the loop with machine-verified tickets instead of suggestions; and it is the only tool covering both China and global engines.

Migrating from GeoLook?

fastergeo metrics --format geolook re-scores your existing GeoLook samples directly — zero migration needed.
