第一步检查

AI 爬虫眼中的你的网站，长什么样？

这个扫描就是产品本身，不是诱饵——与 CLI 同一套六维体检，测你的一个页面，免费、免注册。我们扫过的网站里两种失败最常见：页面在不执行 JavaScript 的爬虫眼里是空白，以及 robots 规则悄悄封错了爬虫。

常见问题

常被问到，直接回答。

什么是 GEO（生成式引擎优化）？

让 AI 引擎——ChatGPT、Claude、Perplexity、豆包、DeepSeek——在用户询问推荐时提及并引用你品牌的实践。 SEO 优化的是链接排名；GEO 优化的是成为答案本身的一部分。

FasterGEO 免费吗？

免费。Apache-2.0 开源，自托管。自带引擎 API Key，或用零 Key 的人工采样表。数据永远不离开你的电脑。

覆盖哪些引擎？

两个市场共十八个：海外 ChatGPT、Claude、Gemini、Grok、Perplexity；国内 API 直连智谱 GLM、豆包、 DeepSeek、Kimi、MiniMax、通义千问、文心一言、讯飞星火——无公开 API 的引擎（百度 AI、Google AI Overviews）走人工采样表。

必须要 API Key 吗？

不必须。站点体检完全不需要 Key。采样有什么 Key 用什么 Key；没 Key 的引擎走人工采样表，导入同一套指标管线。

为什么该信这些数字？

因为你不需要凭信任。每个指标都有公开定义并可追溯到计算它的代码——见方法论。测不出的显示未测，绝不填零。判定附逐字引用。而且本页每个统计都注明来源——产品对你的内容强制执行的编造门禁，同样约束着我们自己的营销。

和 AI 可见度监测工具有什么不同？

三点。它测漏斗头部——AI 到底认不认识你、有没有把你认成别家公司——附引用证据。它闭环——发现变工单，工单带机器可验收标准并自动复查。它是唯一同时覆盖中国与海外引擎的工具。
